# 《小纸条 (Slow Notes 500m)》设计系统与工程开发规范

本 Skill 为《小纸条》社交 App 的全局核心指南。任何对本项目的页面新增、样式修改、业务交互或代码重构，必须百分之百遵循本规范，杜绝风格脱节、杜绝原生简陋控件、杜绝破坏慢社交沉浸感。

---

## 一、 核心产品哲学与灵魂法则 (Core Philosophy)

### 1. 坚守“慢社交”的纯粹性 (Zero Paid Acceleration)
* **绝对杜绝商业加速**：严禁出现任何形式的“1元提速”、“极速券”、“跳过等待”等破坏慢社交意境的付费特权。
* **物理距离即传递延迟**：纸条以物理距离折算传递时间（例如 500 米内即时滑入，1~3 公里纸飞机滑翔数分钟），用户传递的是“期待”与“纸短情长”。
* **变现重心放在情怀增值**：
  * 🔏 珍藏特权火漆印章外观包（古铜月相印、玫瑰金猫爪印、欧式皇家徽印）
  * 📜 典藏和纸与星空信笺套装（京都古法和纸、星空流光纸、午后羊皮卷）
  * 🪵 治愈桌洞拟物化装扮皮肤（雨夜咖啡馆、京都老书屋、温室花房）
  * 🎁 《小纸条》实体文创慢寄礼盒（手工黄铜书签 + 和纸胶带盲盒 + 慢递信笺）
  * 🏪 本地小店 500m 生活圈定向便签（无侵入式的周边手作小店优惠）

### 2. 前置地理隐私保护 (Privacy by Default)
* **强制全链路实行模糊距离展示**：
  * 严禁在任何界面展示精确的建筑物名称、精确门牌号或精细到米级的距离（如“距离 328 米”）。
  * 统一使用 `formatDistance` 提供的阶梯式浪漫生活圈区间：
    * `<= 50m`: `在身边 50 米内`
    * `<= 100m`: `在 100 米内`
    * `<= 300m`: `在 300 米内`
    * `<= 500m`: `在 500 米内`
    * `<= 1000m`: `在 1 公里内`
    * `> 1000m`: `在 1 公里外`
  * 既保留“同在周边”的偶遇浪漫感，又彻底杜绝线下人身追踪隐患。

## 二、 吉卜力治愈手账轻拟物设计系统 (Ghibli Design System)

严禁做出任何现代冷冰冰的中后台 Admin 风格或粗糙廉价感！全站严格贯彻【吉卜力慢生活 · 治愈手账轻拟物】：

### 1. 统一定制调色板 (Color Palette)
| 角色 | 色值 | 含义与使用场景 |
| :--- | :--- | :--- |
| **画布底色** | `#F7F5F0` / `#FFFDF8` | 温润米白、和纸浅底，作为全局背景 |
| **深木主色** | `#3E2723` | 课桌深褐木质，用于核心主行动按钮、强标题 |
| **陶土暖橙** | `#C25B38` | 手作质感暖橙，用于高亮行动项、强调点缀 |
| **黄铜金** | `#D97706` | 复古金属、飞行航迹雷达高亮 |
| **火漆绯红** | `#B91C1C` / `#7F1D1D` | 复古火漆印章、私密信封封口徽标 |
| **水洗靛蓝** | `#4A6B82` | 地理位置、超链接与信息流弱强调 |
| **文字灰阶** | 主 `#2C2420` / 次 `#70665F` / 弱 `#A8A096` | 柔和深炭褐，杜绝刺眼的 `#000000` 纯黑 |

### 2. 拟物细节与触感语言
* **和纸撕边胶带**：在便签纸、手写卡片顶部带有半透明白底、虚线撕边胶带条（`.washi-tape-strip`）。
* **微凹凸阴影**：卡片使用温和弥散投影 `box-shadow: 0 3px 10px rgba(62, 39, 35, 0.06)`，杜绝生硬浓黑描边。
* **圆角层次**：按钮/药丸 `16px - 18px`，卡片 `12px`，底部滑出抽屉顶角 `20px`。

### 3. 🚨 交互设计大忌与红线 (Strictly Prohibited Anti-Patterns)
1. **❌ 绝对严禁调用原生未经封装的 `uni.showActionSheet` 或原生居中白底 `uni.showModal`**：
   * 原生控件在 Web H5 上是生硬冰冷的黑白弹窗，直接打破用户的沉浸感。
   * **✅ 必须使用全局统一的「拟物手账抽屉 (Bottom Drawer)」**，底部带提手小把手、毛玻璃遮罩、信纸卡片色块与火漆实物浮雕微章！
2. **❌ 绝对严禁使用“说明书式”长句子作为界面 Label**：
   * 杜绝诸如“便签贴纸色彩挑选属于此地心情的彩纸底色”、“想要亲手写字？点击进入真迹手写绘板”这类啰嗦口号把界面撑爆折行。
   * 保持克制、优雅、留白。
3. **❌ 绝对严禁 Emoji 满屏泛滥堆砌**：
   * 保持单屏 Emoji 数量克制，不搞十几个花里胡哨的大图标，突出主要操作。

## 三、 各核心页面交互规范 (Screen Specifications)

### 1. 慢纸条聊天会话页 (ChatSheet)
* **顶栏**：
  * 左侧 `‹ 返回`；居中好友名 + `📍 {{ formatDistance }} · 慢纸条互传`；右侧木质温润小胶囊 `🪟 进TA桌洞`。
* **消息气泡**：
  * 真实信笺卡片质感，支持 4 款和纸底纹切换（京都和纸、星空流光纸、樱花纸、牛皮卷）。
  * **状态严谨**：历史接收消息直接显示 `📬 已滑入桌洞 · 时间`，严禁对已读旧消息误显示“天空传递中”！
  * **火漆破印**：收到带火漆的私密纸条时，轻触戳破火漆封口（破印微动效），方可展信。
  * **桌洞珍藏**：纸条右下角提供 `📌 存入桌洞`，一键收入个人桌洞抽屉。
* **底部书写托盘 (Stationery Tray)**：
  * 上层：文具胶囊栏 `[ ✍️ 手写纸条 ]` `[ 🔏 火漆盖章 ]` `[ 📜 特权信纸 ]` `[ 🌸 戳印 ]` + `0/70 字`。
  * 中层：微暖和纸自适应多行输入台。
  * 右侧：实体微悬浮 `🕊️ 寄出` 按键，输入字后激活为陶土深褐色，伴随纸飞机起飞动画。

### 2. 贴便签发布页 (PublishSheet)
* **顶栏**：极简 `取消` | `贴便签` | `贴上`（激活时深木褐高亮）。
* **便签纸画布**：顶部贴和纸胶带，便签底色动态随选（黄、粉、蓝、绿、牛皮），内嵌底部色盘与字数 `0/500`，杜绝冗余重复跳转。
* **场景与属性卡片**：分组卡片容纳分段器（关注动态/地图便签/求助）、二次元同好、500米位置、可见度。
* **提交动效**：拟物刷浆糊动效，丝滑贴上地图。

### 3. 写字台桌洞主页 (DeskHoleTab)
* **全景视口**：面对窗户的实木写字台，白纱窗帘随风轻动，窗外呈现实时/切换天气（晴空光晕、雨天雨丝、静夜星月）。
* **回忆录日记本**：复古线装翻页、侧边做旧多层纸张。
* **桌洞抽屉**：拉开抽屉查看收到的秘密纸条，支持一键回信。

## 四、 工程与发布标准 (Engineering Standards)

1. **框架与语法**：
   * Uni-App Vue 3 `<script setup lang="ts">` + SCSS 模块化样式。
   * 状态管理通过 `useAppState.ts` 与 `services/storage.ts`、`services/slowNotesService.ts` 保持纯粹契约。
2. **构建与自测**：
   * 修改后必须运行 `npm run build:h5`，保证 0 编译警告与 0 错误。
   * 必须通过浏览器 QA 智能体真机走查截图回验。
3. **双分支发布闭环**：
   * 提交源码：`git -c http.proxy="" -c https.proxy="" push origin master`
   * 部署在线：`npm run deploy:h5`（或将 `dist/build/h5` 强推至 `gh-pages` 分支）
   * 确保用户在 [https://chase-xue.github.io/map-social-500m/](https://chase-xue.github.io/map-social-500m/) 随时获得最新体验。
