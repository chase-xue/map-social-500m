# 500米地图生活圈 (Map Social 500m)

基于 **uni-app (Vue 3 + Vite + TypeScript)** 打造的高保真、超近距离 LBS 真实邻里生活圈社交系统。采用严格的 **微信 8.0 原生规范** 与 **Zenly 风格沉浸式地图**，支持微信小程序、手机 App（iOS/Android）及 H5 网页。

> 📖 **完整交互手册与开发设计规范**：详见 [docs/INTERACTION_MANUAL.md](docs/INTERACTION_MANUAL.md)。后续所有产品交互设计、前后端开发与页面迭代均须严格遵循此手册。

## 📱 核心架构与四大底层页签

应用底部导航栏固定采用微信标准原生高度，四大主页签顺序严格定义如下：

```
[📍 地图]  ───────  [👥 通讯录]  ───────  [💬 聊天]  ───────  [👤 我]
 (第1位)             (第2位)             (第3位)            (第4位)
```

| 序号 | 核心页签 | 图标规范 | 核心功能与交互 |
| :---: | :--- | :--- | :--- |

| **2** | **通讯录** | 未选：1.8px 经典线性双人像<br>激活：分层遮罩微信绿双人像 | 微信标准搜索栏、新的朋友（待处理申请红点）、500m 邻友雷达、邻友字母排序与直达私聊 |

## 🎨 页面交互设计准则 (WeChat Native Standard)

1. **全屏二级流转（严禁桌面式浮动弹窗）**：
   - 彻底废除居中浮动小窗与黑色遮罩弹窗；
   - 状态详情（`DetailSheet`）、个人资料（`MyProfileSheet`）、详细资料卡（`UserCardModal`）、发状态（`PublishSheet`）、私聊窗口（`ChatSheet`）等次级页面**一律采用全屏铺满容器（`position: absolute; inset: 0; z-index: 100;`）**，配备微信原生 `‹ 返回` 顶栏；
2. **高德地图纯净视界**：
   - 三层底层 CSS 规则与动态拦截，100% 抹除高德地图 Logo、审图号与版权水印，打造沉浸式极简地图；
3. **点赞与评论流原生化**：
   - 朋友圈原汁原味 `#f7f7f7` 灰底点赞名单；
   - 底部固定评论栏：当前身份头像展示、白底圆角输入框、📷 相册选图与微信绿发送按钮；
4. **全屏大图预览灯箱**：
   - 采用纯黑底、`<swiper>` 横向滑动的沉浸式灯箱，替代易引发虚拟路由错误的 `uni.previewImage`。

## 🚨 救命呼救与邻里急事求助机制

- **双档位分级**：
  - **普通急事 (🆘 HELP)**：借工具、问路、寻物、寻宠等，在生活圈内广播；
  - **救命呼救 (🚨 EMERGENCY)**：特大人身安全紧急呼救，地图打上特大红色脉冲警报标记，并在全站顶部闪烁广播；
- **发起人闭环与归档**：
  - 仅发起人可见 `✅ 问题已解决，关闭求助` 按钮；
  - 关闭后状态标记为已解决，提示在 2 小时后平滑淡出归档。

## 🌿 Git 分支管理与对外发布规范 (Branch & Release Protocol)

本项目严格采用 **源码分支** 与 **对外发布分支** 分离的双分支管理规范：

| 分支名 | 分支定位 | 承载内容与职责 | 维护要求 |
| :--- | :--- | :--- | :--- |
| **`master`** | **源码开发分支** | 包含完整的 TypeScript / Vue 3 源码工程、配置文件、样式与文档。 | **代码开发主干**：所有功能迭代、Bug修复、组件重构必须在 `master` 分支提交与合并。 |
| **`gh-pages`** | **对外发布分支** (生产上线) | 仅包含 `npm run build:h5` 编译生成的生产环境纯净静态产物（`index.html`、`assets/`、`static/`）。 | **外部访问基准**：GitHub Pages 绑定此分支对外提供 H5 在线体验，**严禁将未编译的开发源码提交至此分支**。 |

## 🚀 本地开发与对外发布流程

### 1. 本地启动开发
```bash
# 确保在 master 分支
git checkout master

# 安装依赖并启动本地 H5 调试服务器
npm install
npm run dev:h5
```
浏览器访问：`http://localhost:5173`

### 2. 编译生产构建
```bash
npm run build:h5
```
产物输出至 `dist/build/h5` 目录。

### 3. 一键对外发布上线 (部署至 gh-pages)
当在 `master` 分支完成开发与自测提交后，执行以下命令一键打包并推送到对外发布分支：
```bash
npm run deploy:h5
```
该命令会自动编译最新产物并将纯净生产包强制推送至 `origin/gh-pages`，无需手动切换分支，杜绝工作区与依赖污染。

### 4. 线上对外访问地址
- **生产环境公开访问 URL**：[https://chase-xue.github.io/map-social-500m/](https://chase-xue.github.io/map-social-500m/)
- **对应发布分支**：`gh-pages`
